# SNIPER ELITE

A mobile-first tactical shooter prototype for Android built in Godot.

## Project Overview

SNIPER ELITE is an action-heavy stealth and sniper game featuring:
- mission-based progression
- weapon upgrades and loadouts
- enemy AI and patrol routes
- immersive environment chapters
- Android-friendly touch controls and UI

## Current Structure

This repository contains the base folder layout for the game project, ready for scene, script, and asset implementation.
